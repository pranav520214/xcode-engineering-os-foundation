# Domain engine

XCODE is designed around extensible domain adapters.

## Initial domains

- SoftwareDomain
- WebDomain
- AIDomain
- SecurityDomain
- ResearchDomain
- CreativeDomain
- CADDomain

## Domain responsibilities

Each domain can contribute capabilities, tools, knowledge, artifacts, planning rules, validators, safety policies, and output types without forcing the core runtime to know every domain detail.
