# Security architecture

Security is a first-class subsystem in XCODE.

## Core state

- Asset
- AttackSurface
- Threat
- SecurityControl
- SecurityInvariant
- SecurityFinding
- SecurityEvidence

## Integrity tracking

- file hashes
- configuration hashes
- dependency state
- tool operations
- agent modifications
- Git state

## Requirement

The system must distinguish model claims from verified engineering evidence.
