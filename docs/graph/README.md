# Engineering graph

The engineering graph is a first-class model for requirements, code, tasks, evidence, and security state.

## Node types

Project, Repository, Directory, File, Module, Class, Function, Variable, API, Service, Database, Component, Task, Requirement, Decision, Expert, ExpertKeycard, Domain, SecurityInvariant, Threat, Test, Artifact, Memory, Evidence, Event, GitCommit, Prediction

## Relationship types

contains, imports, calls, references, depends_on, implements, inherits, tests, protects, violates, derived_from, supports, contradicts, supersedes, created_by, modified_by, related_to, validated_by, evidenced_by, requires, influences
